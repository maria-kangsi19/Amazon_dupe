
# Amazon Dupe

A static front-end clone of the Amazon.com homepage, built to practice HTML/CSS layout, responsive design, and recreating a real-world e-commerce UI pixel-by-pixel.

## Features
- Recreated Amazon navbar, hero banner, and product grid sections
- Category boxes with product imagery
- Font Awesome icons for UI elements

## Tech Stack
- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/) (via CDN)

## Project Structure
```
Amazon_dupe/
├── index.html       # Page markup
├── style.css        # Styling
├── amazon_logo.png  # Logo asset
├── hero_image.jpg   # Hero banner image
└── box1-8_image.jpg # Product/category images
```

## Getting Started
No build step required — this is a static site.

```bash
git clone https://github.com/maria-kangsi19/Amazon_dupe.git
cd Amazon_dupe
open index.html   # or just double-click the file
```
